## 1. 项目概述

elementskin-union-svc 是 Element-Skin 的独立 Union 联邦站 sidecar 服务。从 element-skin 主仓库拆分而来，以独立 Go module 运行，通过 OAuth2 和 HTTP API 与 Element-Skin 主站通信，通过 Union Hub 协议与联邦网络通信。

### 3.2 内置 UI

| 页面 | 路径 | 功能 |
|---|---|---|
| 用户页面 | / | OAuth 授权 → 角色查询 → 绑定/解绑 → 安全等级 |
| 管理面板 | /admin | API key 登录 → 状态概览 → 全站同步 → Union 管理 → 密钥轮换 → 黑名单 |

### 3.3 鉴权体系

| 认证域 | 中间件 | 覆盖端点 | 机制 |
|---|---|---|---|
| 用户 API（外部调用方） | withBearerToken | 通过 withBearerOrSession | Bearer token → element-skin GetUserInfo 实时验证 |
| 用户 UI（浏览器） | withSessionCookie | 通过 withBearerOrSession | session cookie → sessionStore → access token → GetUserInfo |
| 管理接口 | withRateLimit(withAdminAPIKey) | /api/union/admin/* | API key 常量时间比较 + 10/min/IP 限流（限流在外层防暴力探测） |
| Hub 回调 | withUnionVerify | /api/union/member/* | RSA-SHA256 签名 + nonce 防重放 + 时间戳窗口 |
| Webhook | withWebhookSecret | /api/union/webhook/* | Bearer token 常量时间比较 |

## 4. 部署配置

### 4.1 config.yaml

```yaml
server:
  addr: ""
  port: 8267
  root_path: ""  # 子路径前缀，如 "/union-svc"

elementskin:
  base_url: ""      # Element-Skin 后端 API 地址
  site_url: ""      # Element-Skin 前端地址
  oauth:
    client_id: ""        # 用户授权应用（scope: account.read.self profile.read.owned）
    client_secret: ""
    redirect_uri: ""     # 如 https://example.com/union-svc/oauth/callback
  service_account:
    client_id: ""        # 服务账号应用（scope: profile.read.any）
    client_secret: ""
    scope: "profile.read.any"

union:
  hub_url: ""
  member_key: ""
  admin_api_key: ""      # openssl rand -hex 32
  webhook_secret: ""     # openssl rand -hex 32
  cors_allow_origin: ""
  enable_oauth2: true
  oauth2_sig_private_key_path: "./oauth2_sig_private.pem"
  oauth2_sig_public_key_path: "./oauth2_sig_public.pem"
```

### 4.2 Nginx（子路径部署）

```nginx
location /union-svc/ {
    proxy_pass http://127.0.0.1:8267;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
}
```

Hub 成员地址配 `https://example.com/union-svc`。OAuth redirect_uri 配 `https://example.com/union-svc/oauth/callback`。

### 4.3 Element-Skin 侧配置

在 element-skin 后台创建两个 OAuth 应用：
- 用户授权应用：Authorization Code + PKCE，scope `account.read.self profile.read.owned`
- 服务账号应用：Client Credentials，scope `profile.read.any`

## 5. 安全措施

| 措施 | 防护对象 |
|---|---|
| validateProfileOwnership | 跨用户角色劫持——bind/unbind 前验证 UUID 归属 |
| withRateLimit（限流外层） | admin_api_key 暴力探测 |
| withBearerOrSession（session cookie） | access token 不出服务端，XSS 无法窃取 |
| CSP header（admin UI） | XSS 偷 localStorage 中的 API key |
| admin.js 外部文件 | CSP `script-src 'self'` 合规，无内联脚本 |
| regenerate-keypair confirm | 防误触密钥轮换 |
| regenerate-keypair 读旧恢复 | 轮换失败时恢复旧密钥 |
| status 只返回 bool | 密钥值不泄露 |
| withUnionVerify RSA+nonce | Hub 回调防伪造和防重放 |
| subtle.ConstantTimeCompare | API key/webhook secret 防时序攻击 |
| session cookie HttpOnly+Secure | 防 JS 读取 + 防 MITM |
